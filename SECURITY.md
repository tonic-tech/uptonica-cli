# Security

This CLI handles a bearer token that can read and write data across one or
more Uptonica workspaces. If you find a vulnerability, please report it
privately rather than opening a public issue.

**Contact:** security@uptonica.com (or support@uptonica.com if that alias
isn't live yet)

Please include:
- What you found and how to reproduce it
- The version (`uptonica --version`) and platform
- Anything you can share about impact (does it require a valid token, does
  it affect one workspace or many, etc.)

We'll acknowledge reports and let you know when a fix ships. Please don't
test against production customer data — use your own workspace or ask us
for a sandbox.
